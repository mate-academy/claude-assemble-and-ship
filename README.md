Цей плагін складається з однієї соманди та одного агента:

Агент code-reviewer Перевіряє змінений код на наявність помилок та незрозумілих назв. Використовується одразу після написання або редагування коду.

Команда summarize-changes перелічує кожен файл, до якого було внесено зміни, та надає однорядковий опис змін, що в ньому було внесено, придатний до включення в опис пул-реквесту.
