# QA Kit

A Claude Code plugin for summarizing branch changes and reviewing recent code changes.

## Commands

* `/qa-kit:summarize-changes` — summarizes changes on the current branch.

## Agent

* `code-reviewer` — reviews recent changes for bugs and issues.

## Usage

Load the plugin with:

`claude --plugin-dir .`

Then run `/qa-kit:summarize-changes` or ask Claude to review recent changes.
