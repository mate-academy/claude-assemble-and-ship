# qa-kit

Плагін Claude Code з двома компонентами для швидкої перевірки якості змін перед комітом чи PR.

## Що входить

- **`/qa-kit:summarize-changes`** — команда, яка підсумовує зміни на поточній гілці: перелічує кожен змінений файл з одним рядком опису, у форматі, придатному для опису PR.
- **`code-reviewer`** — субагент, який переглядає нещодавні зміни коду на предмет багів, відсутньої обробки помилок та незрозумілих назв, і повертає список зауважень за пріоритетом (high/medium/low).

## Як користуватися

1. Завантажте плагін локально з кореня репозиторію:
   ```
   claude --plugin-dir .
   ```
2. Запустіть команду підсумовування змін:
   ```
   /qa-kit:summarize-changes
   ```
3. Викличте рев'ю коду, попросивши Claude переглянути нещодавні зміни — він сам звернеться до субагента `code-reviewer`.
4. Після будь-яких правок компонентів виконайте `/reload-plugins`.
