# QA Kit

QA Kit — невеликий плагін для Claude Code, який допомагає підбити підсумок змін на гілці
та швидко переглянути щойно написаний код.

## Що всередині

### Команда `/qa-kit:summarize-changes`

Перелічує файли, змінені на поточній гілці, і дає один рядок опису на кожен файл.
Результат навмисно короткий — його можна одразу вставити в опис pull request.

### Субагент `code-reviewer`

Переглядає нещодавні зміни на баги, відсутню обробку помилок і незрозумілі імена.
Знахідки згруповані за рівнем важливості (high / medium / low), по одному реченню на пункт.
Викликається автоматично — достатньо попросити Claude переглянути ваші останні зміни.

## Як користуватися локально

Завантажте плагін з кореня репозиторію:

```bash
claude --plugin-dir .
```

Далі в Claude Code:

- `/qa-kit:summarize-changes` — запустити команду (ім'я плагіна працює як namespace);
- «переглянь мої останні зміни» — щоб задіяти субагента `code-reviewer`;
- `/reload-plugins` — після будь-яких правок файлів плагіна.

## Структура

```
.claude-plugin/plugin.json   # маніфест: name + version
commands/summarize-changes.md
agents/code-reviewer.md
```

Важливо: у `.claude-plugin/` лежить **тільки** `plugin.json`. Теки компонентів
(`commands/`, `agents/`, `skills/`, `hooks/`) завжди живуть у корені репозиторію.

## Перевірка

Структуру плагіна перевіряє скрипт:

```bash
node .github/scripts/validate-plugin.js
```

Той самий скрипт запускається в GitHub Actions (workflow «Validate plugin») на кожен push
і pull request. Зелений чек підтверджує коректну структуру; те, що компоненти справді працюють,
перевіряється запуском плагіна локально.
