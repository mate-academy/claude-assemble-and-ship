## Mi plugin: mi-primer-plugin

Mi primer plugin de prueba para Claude Code.

### Componentes

- **Comando:** `/mi-primer-comando` - Saluda al usuario y le pregunta en qué puede ayudar
- **Agente:** `revisor` - Revisa código y da sugerencias de mejora

### Cómo usar

1. Instala el plugin
2. Escribe `/mi-primer-comando` en Claude Code
