name: summarize-changes
description: Summarizes the current Git changes and flags bugs, risks, and unintended modifications.
disable-model-invocation: true
---

Review the current Git changes.

Run `git status` and inspect the relevant diff.

Summarize:

- what changed;
- why it appears to have changed;
- bugs or risky behavior;
- unintended or unrelated files;
- missing tests or validation.
